## 2.1 装 pip（系统 Python 无 pip）

系统 Python 3.12.9 没有自带 pip，从 bootstrap.pypa.io 下载 get-pip.py 安装到用户级：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem
# 下载 get-pip.py（无 curl 用 python urllib 也一样）
python3 - <<'PY'
import urllib.request
urllib.request.urlretrieve("https://bootstrap.pypa.io/get-pip.py", "get-pip.py")
PY
python3 get-pip.py --user
```

验证：

```bash
python3 -m pip --version
# pip 26.2.1 from /storage/Users/currentUser/.local/lib/python3.12/site-packages/pip (python 3.12)
```

> 若 pip 报证书错，多半是没带 `SSL_CERT_FILE`。也可以在 `~/.bashrc` 里永久加上 `export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem`。

## 2.2 定义环境变量（建议写进 shell 配置）


## 2.3 三个源、三类装法（先建立心智模型）

| 场景 | 命令模板 |
|---|---|
| **A. 编译型包**（镜像里有 ohos wheel） | `$PY -m pip install --user --only-binary=:all: --index-url "$OH_SRC" <pkg>==<ver>` |
| **B. 纯 Python 包**（PyPI 有 py3-none-any） | `$PY -m pip install --user <pkg>`（走默认 PyPI） |
| **C. 源码树装配**（无 wheel 无纯包） | 下载源码 → `sys.path.insert` 注入 → 替换二进制扩展（见 docs/08） |

**铁律细节：**

1. 场景 A 加 `--only-binary=:all:`：**禁止 pip 回退到源码编译**（没有编译器，回退必失败）。
2. 场景 A 若提示"找不到满足要求的版本"，说明该包在镜像里没有你要的版本——查 simple 索引确认（见 §1.4）。
3. 混装（一个包依赖既含编译型又含纯 Python 依赖）时，**先装编译型，再 `--no-deps` 补纯依赖**。例：

```bash
# torch：编译本体走镜像，纯依赖走 PyPI（镜像没收录 filelock/sympy 等纯包）
$PY -m pip install --user --no-deps --index-url "$OH_SRC" torch==2.11.0
$PY -m pip install --user filelock typing-extensions sympy networkx jinja2 fsspec
```

## 2.4 装完后必做：签名

场景 A（编译型）装完后，**逐个给 .so 签名**：

```bash
find "$SP" -name '*.so' -o -name '*.so.*' | while read s; do
  "$SIG" sign -inFile "$s" -outFile "$s" -selfSign 1 >/dev/null 2>&1 || echo "SIGN-FAIL $s"
done
```

签名是幂等的，重复跑无害。**每次装完编译型包后都跑一遍**，避免漏签。

## 2.5 冒烟测试：pip 本身 + 网络

```bash
# pip 能联网拉索引
python3 -m pip index versions numpy --index-url "$OH_SRC" 2>&1 | head -3
# 预期能看到 ohos 源的 numpy 版本列表（2.2.6 等）
```

若 `pip index` 命令不可用（pip 版本较老），直接抓 simple 页：

```bash
python3 - <<'PY'
import urllib.request
url = "https://pypi.repo.openharmony.cn/artifactory/api/pypi/openharmony-pypi-local/simple/numpy/"
html = urllib.request.urlopen(url, timeout=20).read().decode()
import re
files = re.findall(r'href="([^"]+)"', html)
ohos = [f for f in files if 'ohos' in f]
print("ohos wheels:", len(ohos))
print("\n".join(ohos[-3:]))
PY
```

能看到 `numpy-2.2.6-cp312-cp312-ohos_aarch64.whl` 之类的文件，说明源通、平台标签正确。

## 2.6 备用：离线安装（网络不稳时）

先把 wheel 下载到本地，再离线装：

```bash
# 下载
python3 - <<'PY'
import urllib.request
url = "https://pypi.repo.openharmony.cn/artifactory/api/pypi/openharmony-pypi-local/simple/<pkg>/"
# 从 simple 页解析出 .whl 直链后 urlretrieve
PY
# 离线装
$PY -m pip install --no-index --no-deps --user ./<pkg>-*.whl
```
