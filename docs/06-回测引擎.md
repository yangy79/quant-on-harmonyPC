# 06 · 回测引擎（backtrader / vectorbt）

> 目标：`import backtrader, vectorbt` 全绿，跑通一个真实的双均线回测并画出净值曲线。
> 这两个引擎定位不同：**backtrader 事件驱动（教学/精细控制），vectorbt 向量化（快/批量扫描）**。

## 6.1 backtrader 实装

backtrader **"零强制依赖"**：核心纯 Python + numpy，吃 pandas/CSV，内置 122 个指标。matplotlib 就位后回测曲线可原生画出。安装就是纯 PyPI：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem
$PY -m pip install --user backtrader
python3 -c "import backtrader; print('backtrader', backtrader.__version__)"
# backtrader 1.9.78.123
```

### 双均线金叉回测（60 行内跑通）

```python
# bt_ma_cross.py —— 600519 MA20/50 金叉满仓 / 死叉清仓
import os
os.environ["SSL_CERT_FILE"] = "/etc/ssl/certs/cacert.pem"
import backtrader as bt
import pandas as pd

class MaCross(bt.Strategy):
    params = dict(fast=20, slow=50)
    def __init__(self):
        self.ma_fast = bt.indicators.SMA(self.data.close, period=self.p.fast)
        self.ma_slow = bt.indicators.SMA(self.data.close, period=self.p.slow)
        self.crossover = bt.indicators.CrossOver(self.ma_fast, self.ma_slow)
    def next(self):
        if not self.position:
            if self.crossover > 0:          # 金叉 → 满仓
                self.order_target_percent(target=0.98)
        elif self.crossover < 0:            # 死叉 → 清仓
            self.order_target_percent(target=0.0)

df = pd.read_csv("data/600519.csv", parse_dates=["date"], index_col="date")
data = bt.feeds.PandasData(dataname=df)

cerebro = bt.Cerebro()
cerebro.adddata(data)
cerebro.addstrategy(MaCross)
cerebro.broker.setcash(1_000_000.0)
cerebro.broker.setcommission(commission=0.0008)   # 佣金万 8
cerebro.addsizer(bt.sizers.PercentSizer, percents=98)

print("起始资金:", cerebro.broker.getvalue())
cerebro.run()
print("结束资金:", round(cerebro.broker.getvalue(), 2))
```

### 真实结果（2023-01 ~ 2026-09，600519）

| 项 | 值 |
|---|---|
| 双均线策略 | **−11.99%**（100 万 → ¥880,135） |
| 同期买入持有 | −16.19% |

## 6.2 vectorbt 实装

vectorbt 0.28.5 的依赖链是 scipy + numba（+llvmlite）+ scikit-learn —— **上一章已全部就位**，因此 vectorbt 本体（纯 Python）从 PyPI 直装：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem

# 依赖已在 docs/03、04 装好：numpy/pandas/scipy/numba/llvmlite/scikit-learn/matplotlib
$PY -m pip install --user --no-deps vectorbt==0.28.5   # 纯 Python，--no-deps 避免误拉编译依赖

python3 -c "import vectorbt as vbt; print('vectorbt', vbt.__version__)"
# vectorbt 0.28.5
```

> 若 `pip install vectorbt`（不带 --no-deps）时 pip 尝试从 PyPI 拉编译型依赖并失败，就按上面加 `--no-deps`，依赖已经在系统里了。

### 向量化双均线回测（10 行内）

```python
# vbt_ma_cross.py —— vectorbt 向量化双均线
import os
os.environ["SSL_CERT_FILE"] = "/etc/ssl/certs/cacert.pem"
import pandas as pd, numpy as np
import vectorbt as vbt

price = pd.read_csv("data/600519.csv", parse_dates=["date"],
                    index_col="date")["close"]
fast, slow = price.rolling(20).mean(), price.rolling(50).mean()
entries = (fast > slow) & (fast.shift(1) <= slow.shift(1))   # 金叉
exits  = (fast < slow) & (fast.shift(1) >= slow.shift(1))   # 死叉

pf = vbt.Portfolio.from_signals(price, entries, exits, init_cash=1_000_000,
                                fees=0.0008)
print("总收益: %.2f%%" % (pf.total_return()[0] * 100))
print("最大回撤: %.2f%%" % (pf.max_drawdown()[0] * 100))
```

### 真实结果

vectorbt 与 backtrader 同策略结果一致（同数据、同费率），验证两个引擎口径吻合。

## 6.3 两引擎选型建议

| 维度 | backtrader | vectorbt |
|---|---|---|
| 模型 | 事件驱动（逐 bar 推进） | 向量化（整段数组计算） |
| 速度 | 慢（日线无所谓） | 快（可批量扫参数） |
| 学习价值 | 高（理解撮合/订单/滑点） | 中（黑盒化） |
| 场景 | 精细策略、教学、带复杂逻辑 | 参数扫描、批量回测、信号快速验证 |
| 鸿蒙状态 | ✅ 实测 | ✅ 实测 |

> 教学建议：先用 backtrader 弄懂"一笔订单怎么成交"，再用 vectorbt 做批量实验。本书（配套教材）即用 backtrader 讲原理、vectorbt 做扫描。
