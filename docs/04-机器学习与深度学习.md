## 4.1 lightgbm / scikit-learn / numba / llvmlite：镜像直装

OpenHarmony 社区镜像收录了这些包的 `cp312-cp312-ohos_aarch64` wheel，全部直装：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem
$PY -m pip install --user --only-binary=:all: --index-url "$OH_SRC" \
    lightgbm==4.6.0 scikit-learn==1.8.0 numba==0.67.0 llvmlite==0.49.0

# 装完签名
find "$SP" -name '*.so' -o -name '*.so.*' | while read s; do
  "$SIG" sign -inFile "$s" -outFile "$s" -selfSign 1 >/dev/null 2>&1 || echo "SIGN-FAIL $s"
done
```

验证：

```bash
python3 - <<'PY'
import lightgbm as lgb, sklearn, numba, llvmlite
print("lightgbm", lgb.__version__, "| sklearn", sklearn.__version__,
      "| numba", numba.__version__, "| llvmlite", llvmlite.__version__)
# numba JIT 冒烟（首次会编译，稍等）

@njit
def f(x): return x * 2 + 1

PY
```

> **诚实边界**：numba 的 JIT 在 ohos 运行时可用（`f(21)=43` 验证通过），但长期稳定性仍需观察。vectorbt 依赖 numba，若你的场景只做日线级回测，vectorbt 的 numba 路径运行正常（实测通过）。

## 4.2 torch 2.11.0（CPU）：混装部署

### 4.2.1 安装（编译本体走镜像，纯依赖走 PyPI）

torch 的 wheel 约 84.9 MB，在 OH 镜像里（2.4.0 / 2.11.0 均可）；但镜像**没收录**它的纯 Python 依赖（filelock / sympy / networkx / jinja2 / fsspec 等），必须从 PyPI 混装：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem

# 1) torch 本体（--no-deps 避免 pip 去 PyPI 找编译版）
$PY -m pip install --user --no-deps --index-url "$OH_SRC" torch==2.11.0

# 2) 纯 Python 依赖从 PyPI 补
$PY -m pip install --user filelock typing-extensions sympy networkx jinja2 fsspec

# 3) 签名
find "$SP" -name '*.so' -o -name '*.so.*' | while read s; do
  "$SIG" sign -inFile "$s" -outFile "$s" -selfSign 1 >/dev/null 2>&1 || echo "SIGN-FAIL $s"
done
```

### 4.2.2 验证（全绿实测）

```python
# verify_torch.py
import torch

print("torch", torch.__version__)          # 2.11.0，import 约 3.3s
print("threads:", torch.get_num_threads()) # 20

# 张量 + matmul
a = torch.randn(64, 64); b = torch.randn(64, 64)
c = a @ b
print("matmul:", c.shape, c.dtype)

# autograd + nn + SGD 训练一步
m = torch.nn.Linear(4, 1)
opt = torch.optim.SGD(m.parameters(), lr=0.01)
x = torch.randn(8, 4); y = torch.randn(8, 1)
loss = torch.nn.functional.mse_loss(m(x), y)
loss.backward(); opt.step()
print("autograd/SGD OK, loss =", float(loss))

# numpy 互操作
import numpy as np
t = torch.from_numpy(np.arange(6).reshape(2, 3))
print("numpy<->torch:", t.tolist())

# DataLoader 多进程（num_workers>0 必须写在 .py 里带 main 守卫跑，heredoc 不行）
print("=== torch CPU 部署 OK（无 CUDA，CPU-only 为天然边界）===")
```

```bash
python3 - <<'PY'
# num_workers 多进程测试必须用 .py 文件 + if __name__ == "__main__" 守卫
PY
# 正确姿势：把下面内容存成 dataloader_test.py 再跑
```

```python
# dataloader_test.py —— DataLoader 多进程验证
import torch
from torch.utils.data import TensorDataset, DataLoader

if __name__ == "__main__":
    ds = TensorDataset(torch.arange(100))
    for nw in (0, 2, 4):
        dl = DataLoader(ds, batch_size=8, num_workers=nw)
        n = sum(len(b[0]) for b in dl)
        print(f"num_workers={nw}: {n} samples OK")
```

```bash
python3 dataloader_test.py
# num_workers=0: 100 samples OK
# num_workers=2: 100 samples OK
# num_workers=4: 100 samples OK
```

### 4.2.3 torch 部署结论

| 项 | 实测 |
|---|---|
| import 耗时 | 3.3 s |
| matmul / autograd / nn+SGD / numpy 互操作 | ✅ |
| DataLoader num_workers 0/2/4 | ✅（须 `if __name__ == "__main__"` 守卫——Python 标准要求，非鸿蒙特例） |
| 多线程 | 20 线程可用 |
| 磁盘占用 | ~493 MB |
| **风险评级** | **低** —— 仅 CPU、无 CUDA 为天然边界 |

> 量化场景注意：pyqlib 的因子流程（Alpha158 + LightGBM）**不需要 torch**（仅 `rl` extra 需要）。装 torch 是为了将来做深度学习因子 / 多因子模型。
