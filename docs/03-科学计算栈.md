## 3.3 scipy：必须用 cnb.cool 的 NOFORTRAN 构建（血泪坑）

### ⚠️ 为什么 volces 的 scipy 1.17.1 是死路

volces 镜像的 scipy 1.17.1 在 `scipy.libs` 里**捆绑了 `libgfortran-*.so.5.0.0`**。这个 libgfortran 在本机一 `dlopen` 就 **segfault**（自身构造函数崩溃——与签名、双 libc 均无关，是本机 musl/硬件级不兼容）。PyPI 的 musllinux 预编译版同样崩。**没有可得的跨编译 gfortran 能救**。

### ✅ 正解：cnb.cool 的 scipy 1.16.3（NOFORTRAN 构建）

OpenBLAS 官方已明确 HarmonyOS SDK 无 Fortran 编译器，须用 `NOFORTRAN=1`（C 版 LAPACK）构建。cnb.cool 社区的 scipy 1.16.3 即为此构建：

- `scipy.libs` 里只有 `libscipy_openblas-*.so`，NEEDED 仅 `libc.so`
- **完全不含、不依赖 libgfortran** → 不崩

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem
# 1) 装 NOFORTRAN 的 scipy（注意：不要带 --index-url 指向其他源！）
$PY -m pip install --no-deps --index-url "$CNB" scipy==1.16.3

# 2) 签名（装完必做）
find "$SP" -name '*.so' -o -name '*.so.*' | while read s; do
  "$SIG" sign -inFile "$s" -outFile "$s" -selfSign 1 >/dev/null 2>&1 || echo "SIGN-FAIL $s"
done
```

### 🔧 修复 cnb 轮子的 `_propack` 包 bug（必做，否则 import 链断）

cnb 的 scipy 1.16.3 有打包瑕疵：`scipy/sparse/linalg/_propack/` 目录**缺 `__init__.py`**，且顶层残留一个不完整的 `_propack.cpython-312-aarch64-linux-ohos.so` 抢名（不导出符号）。症状：

```
ImportError: cannot import name '_spropack' from 'scipy.sparse.linalg._propack'
```

修复（两步）：

```bash
# (a) 补 __init__.py 回导出子模块
cat > "$SP/scipy/sparse/linalg/_propack/__init__.py" <<'PY'
from . import _spropack
from . import _dpropack
from . import _cpropack
from . import _zpropack
PY

# (b) 删掉抢名的顶层残次品（用 python，别用 rm）
$PY - <<'PY'
import os
bad = os.path.join(os.path.dirname(__import__("scipy").__file__),
     "sparse", "linalg", "_propack.cpython-312-aarch64-linux-ohos.so")
if os.path.exists(bad):
    os.remove(bad); print("removed", bad)
else:
    print("nothing to remove")
PY
```

### 🔧 修 `_propack.so` 的硬编码绝对路径

cnb 的 `_propack.so` 硬编码 NEEDED 绝对路径 `~/.local/lib/libopenblas.so`。把已签名的 cnb openblas 复制过去（保留其 `.codesign` 段）：

```bash
$PY - <<'PY'
import os, shutil, glob
src = glob.glob(os.path.expanduser(
    "~/.local/lib/python3.12/site-packages/scipy.libs/libscipy_openblas-*.so"))[0]
dst = os.path.expanduser("~/.local/lib/libopenblas.so")
os.makedirs(os.path.dirname(dst), exist_ok=True)
if not os.path.exists(dst):
    shutil.copy(src, dst)
print("libopenblas.so ->", "exists" if os.path.exists(dst) else "MISSING")
PY
# 复制出的新文件若提示无法执行，重新对它签名一次即可
```

## 3.4 全栈冒烟验证

```python
# verify_scipy.py —— 全功能验证
import numpy as np
import scipy
from scipy.linalg import eig, solve
from scipy.optimize import minimize, root
from scipy.integrate import quad
from scipy.sparse.linalg import svds
import scipy.sparse as sp
from scipy import stats, fft
import matplotlib; matplotlib.use("Agg")
import matplotlib.pyplot as plt
from PIL import Image

assert np.linalg.eig(np.eye(3))[0] is not None        # numpy BLAS
w, _ = eig(np.diag([3., -1., 5.])); print("linalg.eig OK")
print("linalg.solve", solve([[3,2],[1,4]], [1,2]))
print("optimize.min", minimize(lambda v:(v[0]-3)**2+(v[1]+2)**2,[0,0]).x)
print("optimize.root", root(lambda x:[x[0]+x[1]-2, x[0]-x[1]-8],[0,0]).x)
print("integrate.quad", quad(lambda t:np.exp(-t**2),0,1)[0])
M = sp.random(40,30,density=0.3,random_state=0); svds(M,k=3)   # propack 路径
print("sparse.svds OK")
print("stats.norm.cdf(0) =", stats.norm.cdf(0))
print("fft OK", fft.fft(np.arange(1,6))[0])
fig, ax = plt.subplots(); ax.plot([1,2,3],[1,4,2])
fig.savefig("_s.png", dpi=80); Image.open("_s.png")
print("=== scipy + numpy + matplotlib + Pillow 全栈 OK ===")
```

```bash
python3 verify_scipy.py
```

全部打印通过即科学计算栈就绪。
