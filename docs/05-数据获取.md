# 05 · 数据获取（akshare + 腾讯源）

> 目标：鸿蒙本机直拉 A 股日线（前复权），15 只股票约 30 秒，带 CSV 缓存。
> 结论先行：**东方财富源拒连、新浪源缺 JS 引擎、腾讯源稳定可用** —— 鸿蒙上的 akshare 一律走腾讯源。

## 5.1 akshare 安装

akshare 1.18.94 已实测可用。安装要点：它的强依赖 lxml 在 OH 镜像有 `ohos_aarch64` wheel（4.9.3~6.1.1），其余多为纯 Python：

```bash
export SSL_CERT_FILE=/etc/ssl/certs/cacert.pem

# 1) lxml 走 OH 镜像（编译型）
$PY -m pip install --user --only-binary=:all: --index-url "$OH_SRC" lxml

# 2) akshare 本体及纯依赖走 PyPI
$PY -m pip install --user akshare

# 3) 签名 + 验证
find "$SP" -name '*.so' -o -name '*.so.*' | while read s; do
  "$SIG" sign -inFile "$s" -outFile "$s" -selfSign 1 >/dev/null 2>&1 || echo "SIGN-FAIL $s"
done
python3 -c "import akshare as ak; print('akshare', ak.__version__)"
```

> 若 akshare 内部依赖 `py_mini_racer`（JS 引擎）/ `curl_cffi` 装不上，**不影响腾讯源日线**——只有新浪源的 `stock_zh_a_daily` 依赖 py_mini_racer。akshare 里这两个是"桩"，保留即可。

## 5.2 三大数据源实测结论（多标的扫描定案）

| 数据源 | akshare 接口 | 鸿蒙实测 | 原因 |
|---|---|---|---|
| 东方财富 | `ak.stock_zh_a_hist` | ❌ 直接拒连 | 本机出口 IP 被东财拒绝（`Connection aborted` / `RemoteDisconnected`） |
| 新浪 | `ak.stock_zh_a_daily` | ❌ 不可用 | 依赖 py_mini_racer（JS 引擎，无 ohos wheel，已 shim） |
| **腾讯** | **`ak.stock_zh_a_hist_tx`** | ✅ **稳定可用** | ~2s/只；返回 `date/open/close/high/low/volume`，支持 `adjust="qfq"` 前复权 |

> **铁律：鸿蒙原生多标的/全市场扫描一律走腾讯源。** 若你只需要少量标的且不想装 akshare，可直接用 `scripts/fetch_tencent.py`（纯 urllib 实现，零第三方依赖，见 §5.4）。

## 5.3 抓取脚本模式（带 CSV 缓存）

```python
# -*- coding: utf-8 -*-
"""腾讯源 A 股日线抓取（带 CSV 缓存，幂等可重跑）"""
import os, time
os.environ["SSL_CERT_FILE"] = "/etc/ssl/certs/cacert.pem"
import pandas as pd
import akshare as ak

BASKET = {
    "600519": "贵州茅台", "000858": "五粮液", "601318": "中国平安", "600036": "招商银行",
    "000333": "美的集团", "002594": "比亚迪", "600276": "恒瑞医药", "601899": "紫金矿业",
    "600900": "长江电力", "600030": "中信证券", "000651": "格力电器", "601012": "隆基绿能",
    "600887": "伊利股份", "300750": "宁德时代", "000001": "平安银行",
}
START, END = "20230101", "20260901"     # 含区间；日期格式 YYYYMMDD
DATA = "data"
os.makedirs(DATA, exist_ok=True)

def fetch_one(code):
    """腾讯源前复权日线，带 CSV 缓存"""
    path = os.path.join(DATA, f"{code}.csv")
    if os.path.exists(path):            # 已有缓存则跳过
        d = pd.read_csv(path, encoding="utf-8-sig")
        if len(d) > 50:
            return len(d)
    for attempt in range(3):            # 重试 3 次，每次间隔 3s
        try:
            df = ak.stock_zh_a_hist_tx(symbol=code, start_date=START,
                                       end_date=END, adjust="qfq")
            if df is not None and len(df) > 50:
                df.to_csv(path, index=False, encoding="utf-8-sig")
                return len(df)
        except Exception:
            time.sleep(3)
    return 0

for code in BASKET:
    n = fetch_one(code)
    print(f"{code}: {n} rows")
```

运行后 `data/600519.csv` 等 15 个文件就位，列含 `date/open/close/high/low/volume`（腾讯源 qfq）。

> 腾讯源字段注意：它返回的成交量单位是"手"、无 amount 列。算 vwap 用典型价 `(high+low+close)/3`（复权口径问题见 docs/08）。

## 5.4 备用：纯 urllib 直拉腾讯源（不装 akshare）

如果你连 akshare 都不想装，腾讯行情 HTTP 接口可以直接调（`scripts/fetch_tencent.py` 即此实现的完整版）：

```python
import urllib.request, json
# 腾讯日 K 接口（qfq=前复权）
url = ("https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?"
       "param=sh600519,day,2023-01-01,2026-09-01,640,qfq")
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
data = json.loads(urllib.request.urlopen(req, timeout=15).read())
# data["data"]["sh600519"]["qfqday"]  → [[date, open, close, high, low, volume], ...]
```

优点：零依赖、抓取快、可自控频率；缺点：无 akshare 的统一封装，需要自己处理代码前缀（6 开头 → `sh`，0/3 开头 → `sz`）。

## 5.5 数据格式约定（供下游 rqalpha / qlib 复用）

| 列 | 说明 |
|---|---|
| date | `YYYY-MM-DD` |
| open / close / high / low | 前复权价 |
| volume | 成交量 |

- **rqalpha**：需要 `total_turnover`（成交额）、涨跌停价 → 由 volume/价格近似生成（见 docs/07）
- **pyqlib dump**：文件名须带交易所前缀小写（`sh600519.csv` / `sz000858.csv`），需要 vwap（典型价代理，见 docs/08）
